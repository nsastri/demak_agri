# 08_demak_agri

Agricultural flood damage analysis for the Demak/Semarang compound coastal
flood risk study (MSc thesis).

## Contents (this repo)
- `21_duration_yield_loss_E49.py`, `22_field_yield_loss_E49.py`,
  `22b_risk_ead_copula.py` — analysis scripts
- `damage_curves/` — rice crop damage function (CSV + reference paper)
- `exposure_agri/` — field exposure data (GeoJSON)

## Not in this repo (shared separately via Google Drive)
- `sfincs_model/` — SFINCS base model (~22 GB)
- `forcings/` — forcing data (add here once sized/finalized)
